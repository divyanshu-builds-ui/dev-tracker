# 📖 Dev Tracker — User Guide

## Getting Started

1. Open `dev-tracker-by-dg.vercel.app`
2. Click **"Get Started with Google"** or **"Continue with GitHub"**
3. Done — you're in!

**Install as App:** Chrome menu → "Install App" or "Add to Home Screen"

---

## Features

### 📊 Dashboard
Your home page. Shows XP level, streak, heatmap, achievements, and recent projects. Everything updates automatically.

### 📁 Projects
Track your projects. Add name, tech stack, status (planning/in-progress/completed/deployed), progress %, links.

### ✅ Tasks
Task manager with priorities (low/medium/high), deadlines, subtasks, and project linking. **Bulk mode** — select multiple and mark done/delete at once.

### 💻 Skills
Track your tech stack. Click **"Skill Packs"** to load pre-made skill sets for Frontend/Backend/Full-Stack/Mobile/DevOps/ML.

### 📝 Daily Logs
Dev journal. Log what you learned, hours worked, and mood. Builds your streak!

### 🎯 Goals
Set weekly/monthly/yearly goals with deadlines. Mark complete when done.

### 🗺️ Roadmap
Choose your developer path (Frontend/Backend/Full-Stack/Mobile/DevOps/ML). Check off topics as you learn them. **"Change Path"** to switch anytime.

### 🔖 Resources
Save useful links. Click **"Load Starter Pack"** for 50 curated resources (docs, tutorials, YouTube, tools, GitHub repos).

### 📈 Analytics
Charts showing weekly hours, skills radar, and project progress. Auto-generated from your data.

### ⏱️ Pomodoro Timer
25-min focus sessions. Auto-switches to break. Tracks sessions per day/week.

### 💾 Code Snippets
Save reusable code with title, language, tags. One-click copy. Filter by language.

### 🐙 GitHub
Connect your GitHub username. Shows your repos, stars, and recent commits.

### 📋 Kanban Board
Drag-and-drop task board (Todo → In Progress → Done). Uses your existing tasks. Tap to cycle status on mobile.

### 📝 Quick Notes
Fast note-taking with 6 color options. Pin important notes. Search by content.

### 🧠 DSA Prep
Interview question tracker. Click **"Load Blind 75"** for 63 pre-loaded questions with LeetCode links. Filter by topic/difficulty. **Bulk mode** for batch actions.

### 🔁 Habits
Daily habit tracker with 7-day grid. Click **"⚡ Suggestions"** for recommended dev habits. Streak tracking per habit.

### 📅 Weekly Review
Auto-generated weekly summary. Week score, stats, highlights. **"Share Card"** downloads an image for social media. **"Export PDF"** for reports.

### 🎓 Certifications
Track courses and certifications. Add platform, progress, completion date. One-click "Mark Complete".

### 🔔 Notifications
Goal deadline reminders and streak warnings. Mark read/unread, clear all.

### 💬 Feedback
Report bugs, request features, or share feedback. Sends email notification.

### ⚙️ Settings
- **Profile:** Name, role, bio, social links, tech stack, location, experience, hire badge
- **Themes:** 6 options (Default Dark, Cyberpunk, Dracula, Nord, Emerald, Light)
- **Export:** JSON data + PDF report + Import JSON
- **Public Profile:** Publish and share your stats link
- **Referral:** Invite friends, earn 100 XP per signup
- **Keyboard Shortcuts:** Full list of all shortcuts
- **Tour:** Re-take the onboarding tour

## Tips

- **Streak Freeze:** You can miss 1 day without breaking your streak
- **Milestones:** Confetti animation at 10/25/50/75/100 tasks or DSA solved
- **Offline:** Red banner shows when internet is gone — data syncs when back
- **Search:** `Ctrl+K` opens command palette to quickly jump between pages
- **Bulk Actions:** Click "Bulk" button in Tasks/DSA to select multiple items
- **Share:** Weekly Review → "Share Card" generates a downloadable image for LinkedIn/Twitter
- **PDF Export:** Settings or Weekly Review → premium branded PDF report
- **Public Profile:** Settings → "Publish Profile" → get a shareable link
